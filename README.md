# PilGlobin Voice Bot

A voice tribute to the spirit of Pidilite. Ask about PilGlobin values, culture,
and ways of working; answers are drawn from the PilGlobin booklet and spoken aloud.

`index.html` is a single self-contained page — 112 embedded voice clips as mono
Opus data URIs, no other assets. No network calls, no build step, no dependencies.
Open the file directly or serve the folder.

The voice is an AI recreation, not actual recordings of Shri M. B. Parekh, and the
page states this to every visitor in the header. Please keep that disclosure intact
in any edit.
